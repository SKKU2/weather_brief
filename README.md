# 기상 브리핑 · 부대운용 건의 도구

브라우저에서 바로 쓰는 단일 페이지 도구입니다. 로그인이 없고, 입력한 자료·설정·API 키는 각자의 브라우저에만 저장됩니다. 이 저장소에는 부대 정보나 위치가 들어 있지 않습니다.

- 위치는 서울(37.57°N, 126.98°E)로 고정되어 있습니다. AI 조언은 기본으로 켜져 있으며, 처음 쓸 때 **이력 · 설정 → 설정**에서 본인의 Claude API 키를 저장하면 됩니다.
- AI 조언(선택)은 각자의 Claude API 키로 동작하며, 키는 설정 화면에서 저장·삭제합니다.
- 우주기상(지자기폭풍 G · 태양복사폭풍 S · 전파두절 R, Kp 지수, 태양 플레어)은 직접 입력하거나 NOAA 우주기상예보센터(SWPC)에서 가져오며, HF 통신·GPS·위성통신 영향을 참고 정보로 보여 줍니다.
- 권고는 참모 건의를 돕는 참고 정보이며 최종 결심은 지휘관이 합니다.
